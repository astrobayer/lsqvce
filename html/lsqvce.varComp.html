lsqvce.varComp

Helmert variance-component estimation, streaming.

Syntax

VC = LSQVCE.VARCOMP(u, batchFcn, nBatch, groupFcn, nGroup) estimates a

Description

separate variance factor for each observation group, iterating until they agree. Use this when the global test rejects but the residuals are clean and structureless -- i.e. when the problem is the WEIGHTS, not the data.

This is the right tool when combining heterogeneous observation types whose relative weighting you do not actually know a priori (the usual case when, say, a range-rate instrument is combined with an interferometric one: both vendors quote a noise figure, and at least one of them is wrong).

Inputs

groupFcn  g = groupFcn(k) returns an nk x 1 vector of group indices in
          1..nGroup for the observations in batch k.
nGroup    number of variance components.

Method

Rigorous Helmert requires the nGroup x nGroup matrix
    H_ij = tr(Qxx N_i Qxx N_j),  N_i = A_i' P_i A_i
which needs only u x u accumulations per group -- perfectly streamable.
The right-hand side is q_i = v_i' P_i v_i. Solving H s = q gives the
variance components. We iterate: rescale P_i by 1/s_i, re-solve, repeat.
The simplified (Foerstner) estimator
    s_i = v_i'P_i v_i / r_i,   r_i = n_i - tr(Qxx N_i)
is also returned, since it is what most textbooks actually use and it
converges to the same fixed point. Rigorous is the default.

Name-Value

'method'   'rigorous' (default) | 'simplified'
'maxIter'  30
'tol'      1e-6      convergence on max|s_i - 1|
'verbose'  true
'minObs'   10        below this a group's component is not estimable
'traceMethod' 'exact' (default) | 'hutchinson'. Entry-point parity with
             lsqvce.vce / lsqvce.redundancy. EXACT stays default and
             authoritative; the redundancy traces tr(Qxx N_g) and the Helmert
             matrix tr(Qxx N_i Qxx N_j) are always formed exactly and drive the
             estimate. With 'hutchinson' those numbers are UNCHANGED; the
             estimator (Ellmer 2018 6.5.6, lsqvce.traceEstimate) adds a machinery
             check tr(N^-1 N)=u on the final normal, returned in VC.traceEstimate.
             It is NOT a per-group redundancy replacement (roadmap item 0).
'probes'    100       number of Hutchinson probes Z.
'traceSeed' []        RNG seed for reproducible probes (default: global stream).
'backend'   'exact' (default) | 'hutchinson'. Which estimator computes the
             VARIANCE COMPONENTS (distinct from 'traceMethod', which only adds a
             machinery check). With 'hutchinson' the WHOLE estimation is delegated
             to lsqvce.vceHutchinson -- the matrix-free Ellmer path that never
             forms the dense inverse. Use it only for LARGE u (thousands); below
             that the exact backend is faster AND exact AND gives the diagnostics.
             Strict Ellmer: the returned VC is then vceHutchinson's SUBSET struct
             (no per-obs fields; adds .redundSE, .estimator='hutchinson'). If
             'checkD' is supplied it FALLS BACK to exact and warns. Roadmap
             item 0, tier T2 (an opt-in SCALE backend).
'seed'      []        RNG seed forwarded to the Hutchinson backend (falls back
                       to 'traceSeed'). Ignored by the exact backend.
'reprobe'   true      forwarded to the Hutchinson backend.

Output Vc

.s          nGroup x 1  final variance components (converged: all ~1)
.scale      nGroup x 1  cumulative weight scaling applied: P_i -> P_i/scale_i
.sigma      nGroup x 1  implied sigma per group = sqrt(scale)
.nObs       nGroup x 1
.redund     nGroup x 1  partial redundancy per group
.iter, .converged, .history
.traceEstimate  present ONLY with 'traceMethod','hutchinson': struct
                (.value/.expected/.relErr/.se/.relSE/.probes/.note) from the
                machinery check tr(N^-1 N)=u. Not a per-group redundancy.

Example

% Two sensors observe the same arcs. Their quoted noise levels are
% almost never both right -- let the DATA say what the ratio is.
g    = [ones(n/2,1); 2*ones(n/2,1)];        % sensor 1 | sensor 2
gsrc = @(k) g(idx(:,k));
VC = lsqvce.varComp(u, src, 4, gsrc, 2);
% VC.sigma        the recovered sigma scale per group
% VC.resolution   its 1-sigma sampling noise (~0.5*sqrt(2/r_g))
% VC.significant  is the correction BIGGER than that noise?
% Do not "correct" your weights by 5%% when the resolution is 6%%.
if any(VC.significant)
    fprintf('sigma ratio = %%.3f\n', VC.sigma(2)/VC.sigma(1));
end
