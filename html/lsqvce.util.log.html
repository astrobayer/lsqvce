lsqvce.util.log

Toolbox-wide logging: one file identifier (logfid) and one screen flag (logflag).

Description

The whole lsqvce toolbox routes its status text and its warnings through this one place, so a caller can capture everything to a log file and decide independently whether it also appears on screen. Every fprintf and warning inside the toolbox was replaced by lsqvce.util.log.msg and lsqvce.util.log.warn.

Two settings (persistent for the session)

NameTypeMeaning
logfid1×1 file idReceives ALL output ("standard output"). Default 1 (command window). Set to an fopen fid to capture status text and warnings to a file.
logflag1×1 logicalWhen true (default) output ALSO appears on screen. When false, output goes ONLY to logfid — nothing on screen (use a real file logfid for a quiet run).

API

CallEffect
lsqvce.util.log.set('fid',logfid,'screen',logflag)Configure either/both settings.
[fid,screen] = lsqvce.util.log.get()Read the current settings.
lsqvce.util.log.reset()Restore defaults (1, true).
lsqvce.util.log.msg(fmt,...)Status line (printf-style), replaces fprintf.
lsqvce.util.log.warn(id,fmt,...)Raise a real warning (lastwarn / state preserved), mirror to logfid, screen only if logflag.
On parallel workers the state is per-process; each worker starts at the default (1, true) unless set inside the worker. For a single captured log, run serially or collect on the client.

Example

fid = fopen('vce.log', 'w');
lsqvce.util.log.set('fid', fid, 'screen', false);   % file only, quiet run
R = lsqvce.engine.adjustVCE(L, days).run();      % all output captured
lsqvce.util.log.reset();
fclose(fid);

% or straight from the entry point:
R = lsqvce.engine.adjustVCE(L, days, 'LogFid', fid, 'LogFlag', false).run();
