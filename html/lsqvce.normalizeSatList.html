lsqvce.normalizeSatList

Normalise a satellite list to a cell of scalar ids.

Syntax

satListCell = lsqvce.normalizeSatList(satList)

Description

Accepts the several natural ways of writing a satellite list and returns a uniform 1xN cell of scalar identifiers, so downstream code can iterate with satListCell{i} regardless of how the caller spelled it.

Input

satList   1xN | Nx1   numeric | char | string | cell   The list. Required.
          Mappings:
            [1 2]        (numeric)      -> {1, 2}
            'CD'         (char row)     -> {'C', 'D'}
            'C'          (1x1 char)     -> {'C'}
            ["C" "D"]    (string array) -> {'C', 'D'}
            {'C','D'}    (cell)         -> {'C', 'D'}

Output

satListCell   1xN   cell   Row cell of scalar ids (char or numeric).

Example

lsqvce.normalizeSatList([1 2])       % -> {[1] [2]}
lsqvce.normalizeSatList('CD')        % -> {'C' 'D'}
