lsqvce.adjustBlock

One-call block-arrow adjustment: accumulate, solve, judge.

Renamed 2026-07-17 from lsqvce.recover so the streaming block-arrow solve pairs by name with lsqvce.adjust (flat, in-memory) and lsqvce.adjustVCE (iterative + variance components). The old name was REMOVED on 2026-07-18 -- all aliases were dropped pre-release -- so calling lsqvce.recover is now an undefined function. See the tombstone page.

Syntax

R = lsqvce.adjustBlock(systems, days)
R = lsqvce.adjustBlock(systems, days, Name, Value, ...)

Description

The single front door over the streaming pipeline. It builds an lsqvce.BlockAccumulator, adds every system, solves the reduced common system, bridges the result into the diagnostics (lsqvce.diagnoseAccum / lsqvce.diagnose), and returns an lsqvce.Results object that carries the solution, the per-observation diagnostics, and the accumulator itself. The six-step dance (accumulator → addSystem → solve → diagnoseAccum → diagnose → report) becomes one line; the lower layers stay reachable on R for experts (R.acc, R.diag).

This performs ONE GLS solve with whatever covariance the loaders supply. The iterative separable refinement (temporal whitening + VCE reweighting) is layered on top by lsqvce.adjustVCE; adjustBlock is its base.

Plot hooks (single-solve, postSolve only)

If a loader was built with lsqvce.makeLoader's 'plotPostSolve', adjustBlock fires that hook once per (system,obsType) stream AFTER the solve — exactly as the lsqvce.adjustVCE postSolve seam does, keyed 'satKey|obsType'. The hook receives ONE ctx struct (.stage='postSolve', .stream, .satKey, .obsType, .sysID, .pass=1, .R (the Results), .x, .exportDir, .showSeconds) and returns a figure; the engine owns the timed show and PNG export via lsqvce.util.showExport. A throwing or figure-less hook is logged (lsqvce:adjustBlock:plotHookFailed) and skipped — plots NEVER break the solve. There is NO 'plotPostModel' seam here: adjustBlock does ONE GLS solve and estimates no stochastic model, so postModel has nothing to fire on; use lsqvce.adjustVCE for that. Raw 4-arg closures (not Loader objects) carry no hooks and are skipped.

Outputs

NameType / sizeDescription
R1×1 lsqvce.ResultsSolution + diagnostics + accumulator: R.x, R.sigma0, R.report(), R.redundancy, R.acc, …

Example

cov.pos = struct('type','arma','ar',[1 -1.6 0.9 -0.25],'ma',1,'sigma',0.7);
cov.kbr = struct('type','diag','sigma',0.2);
Lc = lsqvce.makeLoader(@(d,ot) buildDayC(d,ot), 'sysID','C', 'nl',4, ...
         'obsTypes',{'pos','kbr'}, 'cov',cov, 'arcs',2);
R  = lsqvce.adjustBlock({Lc}, 1:3);
R.report();          % levels 0-4
xhat = R.x;          % common-parameter estimate
