lsqvce.vceHutchinson

Helmert variance components via the Ellmer (2018) stochastic (Hutchinson) trace estimator — a speed-oriented sibling of lsqvce.varComp for large common blocks.

Syntax

VC = lsqvce.vceHutchinson(u, batchFcn, nBatch, groupFcn, nGroup)
VC = lsqvce.vceHutchinson(..., Name, Value)

Description

Estimates a separate variance factor per observation group, iterating until they agree — exactly like lsqvce.varComp, but it never forms the dense inverse Qxx = N⁻¹ and never forms the O(u³) products Qxx·N_g. Every trace it needs is estimated with Z random probes against the Cholesky factor of the normal matrix (Ellmer eq. 6.5.40–6.5.48, via lsqvce.traceEstimate). This is the "full per-group Hutchinson" path, built as a separate entry point so the exact varComp / adjustVCE paths are untouched.

When to use it — and when not to. Use it only when u (the common-parameter count) is large: thousands of unknowns, e.g. a high-degree gravity field. The cost is O(u³ + G·Z·u²) versus varComp's O(G·u³); the crossover is u ≈ Z, so the speedup is roughly u/Z and only materialises for u in the thousands. Below a few thousand unknowns, lsqvce.varComp is both faster and exact and gives the per-observation diagnostics — prefer it. This function also trades accuracy for speed: every trace carries a Monte-Carlo error ~ 1/√Z, worse on low-redundancy or near-rank-deficient groups.
Strict Ellmer — what this deliberately does NOT produce. The estimator returns only per-group scalar traces, so it cannot return the per-observation redundancies r_i = 1 − h_i. It therefore does not provide, and must not be used for: per-observation redundancy, data snooping / outlier flags (snoop / outliers), the (w,r) reliability / MDB numbers, or the integrity guard Σr_i = m − u. If you need any of those, use lsqvce.varComp (exact). This function returns only the per-group components, their scales, and the estimated per-group partial redundancies r_g.

Inputs

Identical to lsqvce.varComp: u (common-parameter count), batchFcn ([A,l,p] = batchFcn(k)), nBatch, groupFcn (g = groupFcn(k), group indices 1..nGroup), nGroup.

Name-value options

NameTypeDefault
method'rigorous' | 'simplified''rigorous'
maxIter1×130
tol1×11e-6 (on max|s_g−1|)
verbose1×1 logicaltrue
minObs1×110
probes1×1100 (Z, Ellmer's value; larger reduces error ~1/√Z at linear cost)
seed1×1[] (global stream; set for reproducible probes)
reprobe1×1 logicaltrue (fresh probe block each iteration)

Outputs

VC is a subset of varComp's struct (no per-obs fields): .s, .scale, .sigma, .nObs, .redund (estimated r_g), .redundSE (its Monte-Carlo standard error), .iter, .converged, .history, .method, .estimable, .resolution, .probes, and .estimator = 'hutchinson'.

Method (matrix-free, Ellmer eq. 6.5.48 shared factor). With N = U'U and Ubar = U⁻¹ raw for a raw u×Z Rademacher block: tr(N⁻¹ N_g) ≈ tr(Ubar' N_g Ubar) gives the redundancies, and tr(N⁻¹ N_i N⁻¹ N_j) ≈ Σ(W_i · W_j) with W_g = U⁻ᵀ(N_g Ubar) gives the Helmert matrix. Ubar and each W_g are formed once per iteration and reused, so no u×u inverse and no O(u³) product ever appears.

Example

% Large common block: estimate 2 variance components without a dense inverse.
VC = lsqvce.vceHutchinson(u, batchFcn, nBatch, groupFcn, 2, ...
         'probes', 200, 'seed', 1);
VC.sigma        % per-group sigma scales
VC.redund       % estimated partial redundancies (+/- VC.redundSE)
