lsqvce.adjustVCE

Iterative separable-GLS engine: it fits the temporal noise model and estimates the variance components, layered on recover.

Renamed 2026-07-17 from lsqvce.SeparableProblem so it pairs by name with the in-memory shortcut lsqvce.adjust (adjust = "just solve it"; adjustVCE = "solve and discover the stochastic model"). The old name was REMOVED on 2026-07-18 -- all aliases were dropped pre-release -- so constructing that class is now an undefined function. See the tombstone page.

"Separable" still appears, correctly, as a COVARIANCE MODEL. type = 'separable' is one of the eight values lsqvce.covModel accepts, and it names the mathematics: the covariance separates into a per-epoch spatial factor and a temporal law, C = σ2D(Rt ⊗ Id)D. That type string was deliberately not renamed when the class was.

Syntax

P = lsqvce.adjustVCE(systems, days)
P = lsqvce.adjustVCE(systems, days, Name, Value, ...)
R = P.groupComponentsBy(key).stochasticModel(...).varianceComponents(...).outer(...).run()

Description

The general separable generalised-least-squares engine. A single GLS solve is the job of lsqvce.adjustBlock; discovering the covariance that solve should use is the job of this class. Two things are unknown a-priori and, if wrong, bias the gravity field itself (not merely the formal errors): the temporal correlation within each observation stream (the SHAPE) and the relative weighting between streams (the SCALE). adjustVCE alternates the two until every stream is white and every variance component is one. It is a handle class with a fluent builder, so the configurators chain and mutate in place.

The model (per group g)

C_g = sigma_g^2 * D_g (R_{t,g} kron I_d) D_g
D_gFIXED per-epoch scaling from the loader (e.g. the PPP epoch covariance). Never estimated here.
R_{t,g}TEMPORAL correlation, the same on every one of the d axes. ESTIMATED — the SHAPE.
sigma_g^2one scalar variance component per group. ESTIMATED by VCE — the SCALE.
kron I_dno cross-axis correlation; this is what makes the whitener separable and cheap (see lsqvce.separableWhiten).

The two-layer loop

initial weights (sigma_g^2 = 1, R_{t,g} = white)
       |
  (*)  v  SOLVE ......... lsqvce.adjustBlock (block-arrow GLS)
       |
       |  SHAPE (within group): re-estimate R_{t,g}
       |    collectResiduals -> residualAcv -> selectArAcv
       |
       |  SCALE (between groups): VCE (Helmert), one sigma_g^2 per group
       |    lsqvce.vce: sigma_g^2 = ||w_g||^2 / r_g  (redundancy pass)
       |
       |  REWEIGHT: push sigma_g and R_{t,g} back into the loaders as a
       |    per-obsType covariance override -> next pass whitens with them
       |
       +-- repeat from (*) until CONVERGED
Wiring, not new numerics. Every numerical step already exists and is tested: adjustBlock, separableWhiten, selectArAcv, residualAcv, collectResiduals, redundancy, vce, diagnoseAccum. This class only alternates and connects them, threading the estimated covariance back through the loader's opt.covOverride hook.

Convergence (both gates, per group)

WHITEevery stream's whitened residuals are serially uncorrelated (selectArAcv reports order 0 / 'white', or the achieved AR order has stopped changing).
BALANCEDevery sigma_g^2 ≈ 1 — VCE no longer wants to move weight.

User-specific adaptation

Read before running on your own data.
  1. Loader. Write buildDay(day,obsType) -> .A .B .l .t (.arcIdx) and wrap it with lsqvce.makeLoader, one Loader per satellite. Give each obsType an initial cov spec ('diag' with a per-epoch sigma for positions, 'arma'/'diag' for range-rate). The loop refines .ar and .sigma; it does not invent D — your buildDay/cov must supply the fixed per-epoch scaling.
  2. nAxes per obsType. 3-D position streams have nAxes=3 (x,y,z share one R_t); range-rate is scalar, nAxes=1. Default: pos→3, everything else→1. Override with P.axes(map).
  3. VCE granularity. Default one sigma per (satellite,obsType). If a group has too little redundancy (VCE warns), coarsen with P.groupComponentsBy('obsType').
  4. Coupled observations (inter-satellite range-rate). The block-arrow model has one local block per system, so an observation depending on two satellites' arc states (KBR/range-rate between C and D) cannot be a third system. Merge C and D into one system with a stacked local block [y_C | y_D] (nl = nl_C + nl_D) carrying all obsTypes; each obsType's buildDay fills the sub-columns it touches (posC→first block, posD→second, rr→both). Use distinct obsType names and group VCE by 'obsType'. See demo_grace_dataLoader (examples/) for a worked template. (If the range-rate depends only on the gravity field, add it as a third system with nl = 0 instead.)
  5. Independent systems. A satellite with NO inter-satellite link (e.g. a positions-only spacecraft) is simply a SEPARATE loader with its own sysID and its own local block, sharing the common field. The demo adds satellite E this way (sysID 2, posE only) alongside the C/D pair, so L = {Lpair, Le} and VCE by 'obsType' yields four components.
  6. Parametrisation pipe. demo_grace_dataLoader passes the unknowns as makeLoader's 'common'/'local' 14-column tables (so nc/nl are DERIVED) and a 'procOpt' struct, all piped to the day-builder's 3rd/4th/5th args.
  7. Priors. A decent starting sigma and AR order shorten the loop but are not required; sigma_g^2 = 1 and a white start both converge.

Loader-contract additions used by the loop

Two optional additions to lsqvce.makeLoader power the loop, both backward compatible:
  • opt.covOverride.bySys.(satKey).(obsType) — a per-satellite covariance override (keyed on the injected opt.sysID). This is how a distinct sigma_g and AR law reach each stream while all loaders share one UserOpt. The old flat opt.covOverride.(obsType) form still works.
  • 'epochCov', an optional @(day,obsType) hook handing the fixed per-epoch D directly to residualAcv for exact separable de-scaling. Without it, the loop falls back to the scalar-sigma whitened-residual path.

Empirical stochastic modelling: P.empiricalStochastic() and P.validate(R)

empiricalStochastic() is a single, named front door that runs empirical stochastic modelling of the observation noise end to end. It adds no new numerics — it fixes the canonical ordering of steps the loop already implements, checks the homogenisation precondition, and attaches the acceptance test. The observation noise covariance is discovered from the postfit residuals and iterated to self-consistency, then validated by the agreement of formal and empirical parameter errors (Ellmer 2018 §6.5; Kvas et al. 2019 — see references below).

R = P.groupComponentsBy('obsType').empiricalStochastic();   % homogenise -> loop -> validate
R = P.empiricalStochastic('homogenise',true,'validate',true,'alpha',0.01,'report',true);
E = P.validate(R);                              % the acceptance test, standalone

The steps, each mapped to the toolbox call that performs it:

StepWhatToolbox call
0 homogenisePositions carry their fixed per-epoch PPP covariance as D (rotated to along/across/radial). Preflight only checks this; it never re-estimates D.epochCov / Cep (makeLoader)
1 start whitesigma_g²=1, R_t=I unless a prior override is present.—
2 solveOne block-arrow GLS pass under the current covariance.adjustBlock
3 postfit residualsDescaled by the fixed D so the ACV is the temporal law only.residualAcv
4 shape (colour)Re-fit the per-stream temporal AR law; whiteness by a Ljung–Box portmanteau test.selectArAcv
5 scale (level)One Helmert variance component per group, folded into the override.vce
6 iterateRepeat 2–5 until every stream is white and every sigma_g² ≈ 1 (typically ~3 passes).the loop
7 validateCompare formal (sqrt(diag(Cxx))) against empirical error scale; report per-stream whiteness p-values and per-group sigma; single accept/reject verdict.P.validate
Why the validation matters. A self-consistent model (sigma0 → 1, residuals white) is necessary but not sufficient. The external check is that the formal parameter errors — which depend on both the geometry and the assumed noise — match the empirical error scale. Good agreement means the formal covariance can be trusted directly and no separate error calibration is needed (Kvas et al. 2019). validate() returns a struct with .sigma0, per-group .sigma/.sigmaOffset, per-stream .pWhite/.white, .formalStd, .empOverForm and the overall .accepted verdict; with empiricalStochastic('validate',true) it is also attached at R.history.empiricalStochastic.
Homogenisation warning. If a 3-D position stream has no epochCov/Cep, step 0 raises lsqvce:adjustVCE:notHomogenised — the loop still runs, but would whiten positions with a scalar sigma, which is not the separable model. Supply D via the loader, or pass 'homogenise',false if the scalar D is deliberate.
