lsqvce.poolGroups

Suggest (or build) a coarser VCE grouping for groups whose redundancy is too low to estimate a reliable variance component.

pool = lsqvce.poolGroups(vc)
pool = lsqvce.poolGroups(vc, Name, Value, ...)

A variance component estimated from r_g observations has a relative standard error of about 0.5*sqrt(2/r_g), so below a redundancy floor the estimated sigma_g is mostly noise. The remedy is to POOL such groups with a neighbour (or with each other) so their combined redundancy clears the floor. This helper reads a finished VCE result, identifies the under-redundant groups, and returns a remapping from the old group keys to pooled keys plus a ready-to-use grouping function for the next pass.

It does not re-solve. Pooling changes the grouping, which changes the whole VCE fixed point, so the honest workflow is: pool → re-run VCE with the new grouping → re-check. This function gives you the new grouping; you re-run.

Input

NameSizeTypeDescription
vc1×1struct a result from lsqvce.vce or lsqvce.varComp, carrying at least .groups (1×G keys), .r (G×1 redundancy), and optionally .sigma (used by the 'nearest' strategy and the printed report).

Name-value options

NameDefaultDescription
floor50 redundancy floor r_min; a group with r_g < floor is a pooling candidate.
strategy'mergeLow' 'mergeLow' merges ALL below-floor groups into one pooled group; 'nearest' merges each below-floor group into the above-floor group whose sigma is closest (needs vc.sigma).
poolKey'pooledLow' label for the merged group under 'mergeLow'.
verbosetrueprint a short report.

Output

FieldSizeTypeDescription
.map—containers.Map oldKey (char) → newKey (char); identity unless pooled.
.newGroups1×Gnewcell distinct new group keys after pooling.
.remap1×1function_handle @(oldKey) -> newKey; compose with your existing groupBy.
.indexRemapG×1double newIndex(oldIndex), for numeric-index groupings.
.pooled1×Pcell the old keys that were pooled.
.floor1×1doublethe floor used.
.changed1×1logical true if any pooling happened.

Example

vc  = lsqvce.vce(accFcn, 'groupBy','obsType');   % some groups thin
pl  = lsqvce.poolGroups(vc, 'floor', 80);
if pl.changed
    % re-run VCE with the coarser grouping (string-key example):
    newGroupBy = @(varargin) pl.remap(oldGroupBy(varargin{:}));
    vc2 = lsqvce.vce(accFcn, 'groupBy', newGroupBy);
end
