lsqvce.Results

The outcome of a recovery: solution, diagnostics, provenance.

Syntax

R = lsqvce.Results(sol, D, acc, diagSol, batchFcn, nBatch, systems)

Description

Returned by lsqvce.adjustBlock (and, later, lsqvce.adjustVCE). It gathers everything a user needs to read and judge an adjustment in one object, and keeps the lower layers reachable for experts. You rarely construct it yourself; you receive it from recover and call R.report().

The two iteration readers

convergence() and summary() read the same R.history and reduce it along opposite axes, which is why both exist:

MethodOne row perReduced acrossAnswers
R.convergence()iterationstreamsWhen did the loop settle, and did it?
R.summary()streamiterationsWhat did each stream end up as?

A converged loop can still hide one stream that never whitened: the per-pass view reports only the worst p-value, without naming its owner. Both raise lsqvce:Results:noHistory on a Results from a single solve, which does not iterate.

Example

R = lsqvce.adjustBlock(systems, days);
R.report('verbose', true);
if ~R.converged, warning('did not converge'); end
x = R.x;   s0 = R.sigma0;
