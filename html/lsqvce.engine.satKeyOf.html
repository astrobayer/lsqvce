lsqvce.engine.satKeyOf

Valid struct field name for a satellite identifier.

Syntax

key = lsqvce.engine.satKeyOf(satId)

Description

The single place that defines the satellite-key convention shared by the GRACE-FO example drivers ITERATESEPARABLE (which WRITES temporalModel.(key).(obsType)) and GRACELOADER (which READS it) and by LSQVCE.ENGINE.RESOLVESATSPECS, so they can never drift.

Input

satId   1x1 | 1xk   char | string | numeric   Satellite identifier, e.g.
                                               'C', "D", or 1. Required.

Output

key     1xm         char   A legal MATLAB struct field name: "s_" + satId
                            passed through matlab.lang.makeValidName
                            ('C' -> 's_C', 1 -> 's_1').
