lsqvce.leverageBlocks

Precompute the small matrices LSQVCE.LEVERAGE needs.

Syntax

blk = LSQVCE.LEVERAGEBLOCKS(Ncc_red, Nll, Nlc)

Description

Called ONCE PER SYSTEM, then reused for every arc of that system. All of the O(nc^3) and O(nl^3) work happens here; LSQVCE.LEVERAGE is then O(m*nc^2/2) per arc with no further factorisations.

Input

Ncc_red  nc x nc  the TOTAL reduced normal matrix, summed over ALL systems
                  (this is the joint-inverse part -- do not pass one
                  system's Ncc)
Nll      nl x nl  this system's local normal matrix (regularised, as used)
Nlc      nl x nc  this system's cross block

Output

blk.Lc   chol(Ncc_red, 'lower')
blk.Ll   chol(Nll,     'lower')
blk.G    inv(Nll) * Nlc            nl x nc
blk.SG   Sxx * G'                  nc x nl
blk.GSG  G * Sxx * G'              nl x nl

Staleness

These blocks depend on the variance components through the whitening. They
MUST be rebuilt at every VCE iteration. LSQVCE.LEVERAGE warns if it detects a
mismatch (leverage outside [0,1]), but it cannot always tell.

Example

blk = lsqvce.leverageBlocks(Ncc_red_total, Nll_s, Nlc_s);
for each arc of system s
    h = lsqvce.leverage(Aw, Bw, blk);
end
See also: lsqvce.leverage, lsqvce.redundancy
