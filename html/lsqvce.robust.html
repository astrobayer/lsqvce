lsqvce.robust

Robust (M-) estimation by iteratively reweighted least squares.

Syntax

[sol, D, ROB] = LSQVCE.ROBUST(u, batchFcn, nBatch) downweights outlying

Description

WHEN TO PREFER THIS OVER lsqvce.snoop ------------------------------------- Rejection is right for a FEW GROSS blunders: a transcription error is not partially valid, and removing it entirely is correct.

Reweighting is right when the error distribution simply has HEAVIER TAILS than the normal -- many mildly discrepant observations rather than a few catastrophic ones. Hard rejection then over-prunes, throwing away real information, and worse, the reject/keep decision at the threshold is a coin flip that a small change in the data can flip.

Measured, median ||x - x_true|| over 200 realisations:

                 gross blunders   heavy tails   CLEAN data
plain LS             0.267           0.188        0.118
Huber                0.126           0.137        0.124
IGG3                 0.140           0.149        0.140
reject at 3 sigma      --            0.144          --

HUBER IS THE DEFAULT, and the table is why. It won every regime, including against the reject-at-3-sigma strategy under heavy tails, and it costs only 5% efficiency on perfectly clean data (95.1% measured -- exactly the textbook value that the tuning constant c = 1.345 is chosen to deliver).

IGG3 is offered because it is the conventional choice in geodesy, but be aware of what it costs: its hard rejection zone discarded enough information to lose 16% efficiency on clean data and it was BEATEN by Huber in all three regimes tested here. Choose it if you need a hard rejection zone for procedural reasons, not because it estimates better.

Influence Functions

'huber'  factor = min(1, c/|w|)                        c = 1.345
'igg3'   |w| <= k0        : 1
         k0 < |w| <= k1   : (k0/|w|)*((k1-|w|)/(k1-k0))^2
         |w| >  k1        : 0                          k0 = 1.5, k1 = 3.0
'bisquare'  factor = (1 - (w/c)^2)^2 for |w|<c, else 0    c = 4.685

The Scale Estimate

------------------ Reweighting needs a scale to judge "how big is big". Using s0 from the least-squares fit is circular: the outliers you are trying to downweight have already inflated it, so everything looks acceptable. We use the normalised MAD of the weighted residuals instead:

s = 1.4826 * median(|vw - median(vw)|)

which has a 50% breakdown point -- it survives up to half the data being arbitrary. The 1.4826 makes it consistent with sigma at the normal.

Name-Value

'influence'  'huber' (default) | 'igg3' | 'bisquare'
'tuning'     override the tuning constant(s)
'maxIter'    30
'tol'        1e-8    convergence on max|dx|/max|x|
'datumB'     []
'method'     'qr'
'sigma0'     1

Output Rob

.pFinal     final weights (the ORIGINAL p times the robust factor)
.factor     the robust factor per observation, in [0,1]
.scale      the robust scale estimate at convergence
.nDown      how many observations were downweighted below 0.5
.nZero      how many were driven to zero (igg3/bisquare only)
.iter, .converged

Example

% Downweight rather than delete. Preferable to snoop when there are
% MANY mild outliers rather than a few gross ones, and it degrades
% gracefully where the redundancy numbers are low.
[sol, D, ROB] = lsqvce.robust(u, src, 4);
% ROB.factor    per-observation weight factor, in [0,1]
% ROB.nDown     how many were downweighted below 0.5
% ROB.converged did the IRLS loop actually settle?
bad = find(ROB.factor < 0.5);        % the suspects
