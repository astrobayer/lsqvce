lsqvce.residualAcv

Temporal autocovariance of de-scaled residuals.

Syntax

[acv, nSamp] = lsqvce.residualAcv(res, satId, obsType, nAxes, maxLag, dayFcn)

Description

Estimates the TEMPORAL autocovariance of one satellite/obsType stream after removing the FIXED per-epoch factor D that the whitener already applied. It pools the ACV over the arcs and over the axes (the axes share one temporal law R_t, the separable model C = D (R_t kron I_d) D). Pooling never crosses satellites: pass a single satId.

De-scaling by D:

nAxes == 1 (e.g. rr)   divide each epoch residual by dayData.sigma(rows)
nAxes  > 1 (e.g. pos)  left-multiply each epoch residual by
                       chol(dayData.Cep(epoch))^-1 (lower)

Input

res      1x1   struct   Collected residuals (see LSQVCE.COLLECTRESIDUALS).
                       Uses res.sys(:).sysID and res.sys(:).obs(:).
                       {obsType, day, arc, v}. Required.
satId    1x1   char|string|numeric   Satellite to select. Required.
obsType  1xk   char|string   Observation type, e.g. 'pos'. Required.
nAxes    1x1   integer >=1   Number of axes per epoch (rr=1, pos=3).
                       Required.
maxLag   1x1   integer >=1   Highest ACV lag to accumulate. Required.
dayFcn   1x1   function_handle   dayFcn(satId, day) -> day struct exposing
                       .arc(iArc).rows / .epochs and .sigma (nAxes==1) or
                       .Cep (nEpochs x nAxes x nAxes). Must already know
                       obsType (bake it into the closure). Required.

Output

acv      (maxLag+1)x1   double   Biased (1/n) autocovariance r(0..maxLag);
                       biased so it stays positive semidefinite and
                       LSQVCE.LEVINSONDURBIN never trips on it.
nSamp    1x1           double    Axis-sample count pooled into acv; feed to
                       LSQVCE.SELECTARACV for its AICc/BIC/PACF reporting.

Example

dayFcn = @(s,d) lsqvce.graceLoader(cfg, s, d, 'pos', 'day');
[r, n] = lsqvce.residualAcv(res, 'C', 'pos', 3, 128, dayFcn);
[a, s2, p] = lsqvce.selectArAcv(r, n);
LSQVCE.LEVINSONDURBIN, LSQVCE.SEPARABLEWHITEN
