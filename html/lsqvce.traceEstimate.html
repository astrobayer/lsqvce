lsqvce.traceEstimate

Monte-Carlo (Hutchinson) trace estimator — Ellmer (2018) §6.5.6.

Syntax

out = lsqvce.traceEstimate(X)
out = lsqvce.traceEstimate(X, 'Name', value, ...)
out = lsqvce.traceEstimate(Xfun, 'size', P, ...)     % matrix-free

Description

Estimates trace(X) for a P×P matrix without forming or inverting it, by probing it with random vectors — the estimator of Hutchinson (1990) as applied in Ellmer (2018, §6.5.6, eqs. 6.5.39–6.5.43) to the variance-component redundancies of ITSG-Grace:

trace(X)  ~=  (1/Z) sum_z  z_z' X z_z
          =   trace( Zbar' X Zbar ),   Zbar = Z / sqrt(Z)

with Z = [z1 .. zZ] a P×Z matrix of independent Rademacher probes (entries ±1 with probability ½, eq. 6.5.40). The estimator is unbiased; its variance falls as O(1/Z). The neglected off-diagonal cross terms z_i' X z_j (i≠j) have zero expectation.

Matrix-free is the point. Ellmer never forms X = U−T Ng U−1. He forms Ubar = U\Zbar once (U is the global normal-matrix Cholesky, shared by every arc), then each trace is trace(Ubar' N_g Ubar). Pass X as a handle @(V)->X*V and supply the shared probe block via 'probes' to exploit this (eq. 6.5.48/6.5.61), turning the whole redundancy sweep into O(Z) solves instead of O(P3).

Inputs

NameDescription
XP×P double, or a function handle @(V)->X*V applying X to a P×k block (matrix-free; requires 'size').
'probes'P×Z double: a fixed raw ±1 probe block to reuse across many traces (e.g. a shared U−1 solve). Overrides NumProbes/Size/Seed.
'numProbes'Z, number of probes (default 100, Ellmer's value).
'size'P, required when X is a function handle.
'seed'RNG seed for reproducible probes (default []: global stream). Uses a private stream, so it never disturbs the caller's RNG.
'distribution''rademacher' (default) | 'gaussian'.

Outputs

NameDescription
tthe trace estimate (unbiased).
info.seMonte-Carlo standard error sqrt(var(q)/Z), q_z = z'Xz. The true trace lies within ~2·se of t with ~95% confidence.
info.relsese/|t| — read this before trusting a single estimate.
info.perProbe1×Z per-probe forms z'Xz (the summands of eq. 6.5.39).
info.Z, .P, .distributionprobe count, dimension, distribution used.
When NOT to trust it. The relative error scales like sqrt(Var/Z), and Var depends on the matrix: for a near-rank-one operator (‖M‖F/trace(M) ~ 1) even Z=100 can leave tens of percent of error. This is why the toolbox keeps the exact leverage path (lsqvce.leverage / lsqvce.redundancy) as the default and offers this estimator only opt-in ('traceMethod','hutchinson'). Ellmer probes the better-conditioned operator U−T Ng U−1 (redundancies in [0,1]) and averages over many arcs and iterations, which is why Z=100 suffices there.

Example — shared-probe reuse (eq. 6.5.48)

U    = chol(N);                       % N = U'*U, computed once
raw  = sign(randn(size(N,1), 100));   % raw Rademacher probes
Ubar = U \ raw;                        % ONE triangular solve, shared
for g = 1:nGroup                      % tr(N^-1 N_g) = tr(Ubar' N_g Ubar)
    t(g) = lsqvce.traceEstimate(@(Z) Ng{g}*Z, 'probes', Ubar, 'size', size(N,1));
end
