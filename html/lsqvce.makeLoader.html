lsqvce.makeLoader

Turn a day-builder into an accumulator-ready Loader.

Syntax

L = lsqvce.makeLoader(buildDay, Name, Value, ...)

Description

You write the ONE part that is genuinely yours — reading your data for a day and returning its design matrix and observations — and makeLoader supplies the protocol the accumulator expects (the 'meta' discovery call, the per-arc slicing, a single-day cache, and the covariance/whitener via lsqvce.covModel). The result plugs straight into lsqvce.adjustBlock or lsqvce.BlockAccumulator/addSystem.

The part you write

buildDay(day, obsType) — or the parameter-driven form buildDay(day, obsType, common, local, procOpt) — returns a struct with

FieldSizeDescription
.Am×nccommon design matrix for the whole day
.Bm×nllocal design matrix (may be sparse)
.lm×1observations
.tm×1epoch timestamps [s]
.arcIdx1×nArc cellrow-index vectors, one per arc (optional; omitted → whole day is one arc)
Determinism required. The accumulator reads each day a second time for residuals and must get identical data back. Seed any RNG from (day, obsType), never from wall-clock or an un-seeded stream.
Arity-aware call. buildDay is called with as many of the five arguments as it declares, so an existing @(day,obsType) builder keeps working unchanged, while a builder that also takes (common, local, procOpt) receives the parametrisation arrays and processing options. common and local have one row per unknown and 14 columns; nc and nl are derived from their row counts.

Inputs

NameType / sizeDescription
buildDay1×1 function_handle@(day,obsType) day builder (above). Required.

Name-value options

NameType / sizeDefault
observationTypes1×T cellstr/stringrequired, e.g. {'pos','kbr'} (alias: obsTypes)
covariance1×1 structrequired; .(obsType) = a covariance spec for lsqvce.covModel (alias: cov)
arcsscalar | vector | struct1 (one arc/day). Scalar N → arcs 1:N; vector → those ids; struct → .(obsType) per type
systemId1×11 (alias: sysID)
numLocal1×1[] (set on L or in the adjustBlock spec; DERIVED from localParams when given) (alias: nl)
commonParamsR×14 cell{}; parametrisation of the COMMON unknowns (one row per unknown), piped to buildDay's 3rd arg. nc derived as size(.,1). Shared across systems — every loader must pass the same value. (alias: common)
localParamsR×14 cell{}; parametrisation of the LOCAL unknowns, piped to buildDay's 4th arg. nl derived as size(.,1). (alias: local)
processingOptions1×1 structstruct(); free-form processing options, piped to buildDay's 5th arg. (alias: procOpt)
epochCovariancefunction_handle[]; @(day,obsType) exposing the fixed per-epoch scaling D for exact separable de-scaling. (alias: epochCov)
plotPostSolvehandle | Map | struct[]; per-obsType plot hook @(ctx)->figHandle fired by adjustVCE after each solve, BEFORE residuals. A single handle broadcasts to all this loader's obsTypes; a Map/struct keys by obsType.
plotPostModelhandle | Map | struct[]; same, fired ONCE after the stochastic model is estimated (ctx also carries the fitted model and VCE weight).
days1×D[]
namechar''
cache1×1 logicaltrue (keep a one-day cache)

The terse aliases (obsTypes, cov, sysID, nl, common, local, procOpt, epochCov) are DEPRECATED but still accepted for one version; using one emits a one-time deprecation notice. Prefer the canonical long forms above.

Outputs

NameTypeDescription
L1×1 structA Loader object with .closure (the 4-arg accumulator callback, handles the 'meta' sentinel), .meta, .batch, .day, the carried .sysID/.nl/.obsTypes/.cov/.name/.days, the derived .nc and the piped .common/.local/.procOpt, and .isLoader = true.

Example

cov.pos = struct('type','arma','ar',[1 -1.6 0.9 -0.25],'ma',1,'sigma',0.7);
L = lsqvce.makeLoader(@(d,ot) myBuildDay(d,ot), ...
        'observationTypes',{'pos'}, 'covariance',cov, 'arcs',2, 'systemId','C', 'numLocal',4);
R = lsqvce.adjustBlock({L}, 1:3);
