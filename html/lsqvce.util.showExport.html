lsqvce.util.showExport

Show a figure briefly, then export it as a PNG — the engine side of the adjustVCE plot hooks.

Syntax

outPath = lsqvce.util.showExport(figH, name, showSeconds, exportDir)

Description

A per-(system,obsType) plot hook (attached to a loader via makeLoader's 'plotPostSolve' / 'plotPostModel') only builds and returns a figure. This helper owns the rest: it brings the figure up, pauses showSeconds so it is visible, exports <exportDir>/<name>.png (creating the folder if needed), and closes the figure. It is defensive — a headless session, an invalid handle, or a hook that returned [] is a silent no-op that returns '', so a plot can never break the solve.

Inputs

NameDescription
figHa figure handle returned by a plot hook (or []).
namebase file name (no extension); sanitised for the filesystem (a 'satKey|obsType' key's | becomes _).
showSecondsseconds to display before continuing. 0 = do not pause; < 0 = show and LEAVE OPEN (pause abs(showSeconds)).
exportDirfolder for the PNG. '' or [] = do not export.

Outputs

NameDescription
outPathfull path of the written PNG, or '' if nothing was exported.
Export prefers exportgraphics (R2020a+) at 150 dpi and falls back to print -dpng on older MATLAB.
