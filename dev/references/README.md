# References

The lsqvce method record follows two doctoral theses. Equation numbers in
`HANDOVER.md`, help texts and the manual refer to **Ellmer (2018)** unless
said otherwise.

**Ellmer, Matthias (2018).** *Contributions to GRACE Gravity Field
Recovery: Improvements in Dynamic Orbit Integration, Stochastic Modelling
of the Antenna Offset Correction, and Co-Estimation of Satellite
Orientations.* Doctoral thesis, Graz University of Technology, Institute
of Geodesy (supervisor: T. Mayer-Gürr). Graz, September 2018.
Open access via the TU Graz repository / TUGRAZonline (search: author +
title).

**Kvas, Andreas (2019).** *Estimation of high-frequency mass variations
from satellite data in near real-time.* Doctoral thesis, Graz University
of Technology, Institute of Geodesy (supervisor: T. Mayer-Gürr). Graz,
November 2019. Open access via the TU Graz repository / TUGRAZonline
(search: author + title).

## Why the full texts are not in this repository

This repository is PUBLIC (HANDOVER.md §5 WP-30, decision D8). The theses
are third-party works without a redistribution licence stated in the
documents themselves, so their full texts are not committed here. For
local Claude Code / container sessions that need the texts, place copies
in `references/local/` — that folder is gitignored and never pushed.
In chat sessions the texts are available as project knowledge.

`BEST_PRACTICE_v4-1.md` (in this folder) is the author's own operating
runbook for container-driven development; Appendices C/D are binding for
working sessions (HANDOVER.md §5 WP-30, Auth note and preflight).
